# Movie Fetcher App

A simple React app that fetches and displays movie data from an API.

---

## Features

- Fetches movie data from an API.
- Displays a list of movies with their title and year.
- Handles loading, error, and empty states.

---

## Installation

### 1. Clone the repository:

```bash
git clone https://github.com/Trust447/fetch_display.git


2. Install dependencies: npm install

3. Start the app: npm start

Your app will be running at http://localhost:3000.
